# Name check: "Wardmap" (preliminary, 26 Nov 2026)

This is a desk search, **not legal clearance**. Ask an IP lawyer to search the Indian Trade Marks Registry (ipindia.gov.in), USPTO, UKIPO and EUIPO before investing in the brand. Classes 9 and 42 matter most.

| Where | Result |
|---|---|
| Package registries | `wardmap` free on npm and PyPI (checked 26 Nov 2026) |
| GitHub | About 17 repositories named wardmap, all with 0 stars, none security-related. The nearest is a hospital ward-management app (`alhadidy/wardmap`) |
| Businesses | WardMaps LLC, Cambridge MA: an antique and reproduction **map retailer**, a different market |
| US / UK / Canada trademark search results | No "WARDMAP" mark found |
| **Closest live mark** | **WORDMAP** (US reg. 2673696, WORDMAP, Inc.), Classes 9, 38 and 42 (software and computer services), live as of January 2026 |

## Assessment

- No identical mark for security software was found.
- **WORDMAP is one letter away and covers software classes.** Whether there is a likelihood of confusion is for a lawyer to judge. The goods differ (a security CLI against WORDMAP's business), but "wardmap" and "wordmap" look and sound alike.
- Lower-risk fallback if counsel advises against the name: keep the code identifier `wardmap` and brand the product "Wardmap CI" or "Breaktrough Wardmap", or pick a new name before v1.0 gains traction. Avoid `reachgate` and `blastgraph` (see docs/PLAN.md §4).

Sources: the WORDMAP record on markinton.com; WardMaps LLC listings on zoominfo.com and bbb.org; GitHub search.
